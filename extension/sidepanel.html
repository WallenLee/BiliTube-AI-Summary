🚀 极简三步上手指南 (2分钟搞定)

1
配置 AI 大模型 API Key

支持 Google Gemini（官方每日 500 次免费配额）、DeepSeek 深度求索、OpenAI、硅基流动 或 本地离线 Ollama：

👉 点击前往 Google AI Studio 免费创建 Gemini Key

获取 Key 后，在插件右上角点击「⚙️ 设置」，选择对应的服务商并粘贴保存即可。

2
下载并启动本地调度服务

为了保障数据隐私与音视频快速切片，本插件采用本地轻量后台驱动（安全无后门）：

📦 点击前往 GitHub 下载完整发布包

解压到电脑任意文件夹，双击运行 start_server.bat 即可（保持窗口在后台运行）。

3
一键总结与本地知识库保存

在任意 B 站或 YouTube 视频播放页，点击插件面板的「✨ 一键总结」，即可生成结构化报告与 Markmap 交互思维导图；点击「💾 保存这篇到本地」可原位保存或覆盖更新到 Obsidian 等本地知识库。

🎙️ 进阶：B 站/YouTube 无字幕视频转写配置 (SenseVoice GPU)

B 站约 40% 的视频（深度访谈、无官方字幕短片、演讲等）没有现成字幕。本插件内置了基于阿里通义 SenseVoice 的本地离线 GPU 语音识别引擎，即使没有字幕也能自动抓取音频高速转写！

1. 所需文件清单：
  • llama-funasr-sensevoice.exe（本地可执行引擎，支持 NVIDIA/AMD/Intel 显卡 GPU 加速）
  • sensevoice-small-q8.gguf（SenseVoice 量化模型，约 200MB）
  • fsmn-vad.gguf（语音端点检测与静音切分模型，约 10MB）
  • ffmpeg.exe（音视频切片工具，建议放入系统 PATH 或固定目录）
2. 一键配置步骤：

将上述文件放置于您的电脑目录中（例如 D:\funasr\），在插件右上角「⚙️ 设置」中，填写对应的路径保存，即可自动启用无字幕深度语音转写！
